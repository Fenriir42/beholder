Open **Compendium** in the campaign sidebar to look up the rules: spells, monsters, magic items, equipment, classes, subclasses, species, backgrounds, feats, class features, species traits and conditions.

## First use

The first time you connect, Beholder downloads the rules once (about 200 KB). After that, the compendium works **offline** and opens instantly. When the server gets an updated version, Beholder downloads it again on its own.

## Searching

Type in the search field: results update as you type, and names that start with your words come first. You can type part of a word (`fireb` finds *Fireball*), and search also looks inside the rules text (`prone` finds everything that knocks a creature prone).

Pick a **Type** to narrow the list. Each type adds its own filters:

| Type | Filters |
|---|---|
| Spells | Level (or cantrips), school, class |
| Monsters | Challenge rating from / to |
| Magic items | Rarity |
| Class features, subclasses | Class |

Click a result to read the full entry: spell details, the complete monster stat block, a class's level table and features, and so on. Every entry shows where it comes from and which rules version it uses.

## Content and credits

The compendium contains the **System Reference Document 5.2.1** (the 2024 core rules), which Wizards of the Coast publishes under an open licence. Content from books you own will come later, as entries your group adds to its own server, never bundled with the app.
