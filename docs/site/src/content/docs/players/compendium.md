Open **Compendium** in the campaign sidebar to look up the rules: spells, monsters, magic items, equipment, classes, subclasses, species, backgrounds, feats, class features, species traits and conditions.

## First use

The compendium shows the rules sources the DM turned on for this campaign. Beholder downloads each source once, the first time you're online after it's turned on (the SRD is about 200 KB, a book between 5 and 220 KB). After that, the compendium works **offline** and opens instantly. When the server gets an updated version, Beholder downloads it again on its own.

## Sources

Besides the SRD 5.2, the server offers open-licensed books from the [Open5e](https://open5e.com) project, which the DM can turn on per campaign under **Settings → Rules sources**:

- **Kobold Press:** Tome of Beasts 1 (2023 edition), 2 and 3, Creature Codex, Deep Magic and Deep Magic Extended, Vault of Magic, Tome of Heroes, Warlock Zine, and a compilation.
- **Kobold Press, Black Flag SRD.**
- **EN Publishing, Level Up (A5E):** Adventurer's Guide, Monstrous Menagerie, Dungeon Delver's Guide, Gate Pass Gazette. Level Up uses different rules from standard 5e.
- **Wizards of the Coast, SRD 5.1** (the 2014 rules).
- **Smaller sets:** Tal'dorei Campaign Setting, Spells That Don't Suck, Open5e Originals.

Every entry shows its source and rules version (2024, 2014 or Level Up).

## Searching

Type in the search field: results update as you type, and names that start with your words come first. You can type part of a word (`fireb` finds *Fireball*), and search also looks inside the rules text (`prone` finds everything that knocks a creature prone).

Pick a **Type** to narrow the list. Each type adds its own filters:

| Type | Filters |
|---|---|
| Spells | Level (or cantrips), school, class |
| Monsters | Challenge rating from / to |
| Magic items | Rarity |
| Class features, subclasses | Class |

Click a result to read the full entry: spell details, the complete monster stat block, a class's level table and features, and so on.

## Same name in several sources

When several turned-on sources have an entry with the same name (Fireball is in both SRDs), the list shows it once, from the source with the highest priority: your server's own entries first, then the SRD 5.2, then 2024, 2014 and Level Up sources. A **+1 version** label marks it, and the entry's page lists the others under **Also in**: click one to read it.
