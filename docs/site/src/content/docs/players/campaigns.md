## Your library

After logging in you land on **Your campaigns**: one card per campaign, with its cover and title. Use the search field to filter by title.

You can be the DM of one campaign and a player in another; they all appear here.

## Join a campaign

1. Ask your DM for the **invite code**: 8 characters, like `ABCD-EFGH`.
2. Click **Join with code** and type it. Case, dashes and spaces don't matter, and an `O` typed by mistake counts as a zero (`0`).
3. The campaign appears in your library as soon as the server confirms.

If the code is wrong you'll see "No campaign uses that invite code". After too many wrong attempts, wait a minute before trying again.

## Create a campaign

Click **New campaign** (or the dashed card at the end of the grid) and give it a title. You become its **DM**. The campaign appears immediately, even offline; it's created on the server as soon as you're connected.

## The campaign home

Click a card to open the campaign. The sidebar takes you back to **All campaigns**, and shows the connection status at the bottom. Other sections (character sheet, notes, compendium, combat, dice log) are marked *Coming soon*.

The home page shows the cover, the title and who the DM is, with four tabs:

- **Characters:** your characters (coming in a later update).
- **Campaign notes:** notes shared with the whole party (coming in a later update).
- **Party:** every member, with a dot and the words *Online* or *Offline*, and a **DM** badge.
- **Settings** (DM) or **Campaign rules** (players): see below.

## Campaign settings (DM)

As the DM you can:

- **Rename** the campaign.
- **Change the cover**: JPEG, PNG or WebP, up to 20 MB and 40 megapixels. The server shrinks it for fast loading. Uploading needs a connection.
- **See and regenerate the invite code.** Only the DM sees the code. Regenerating it stops the old code from working, which is how you close the campaign to new players.
- Set the **rules**:
  - **The DM can read players' private notes:** off by default.  - **What players see of monsters and NPCs in combat:** *Exact* (everything, including HP), *Vague* (Healthy, Bloodied or Near death) or *Hidden* (players don't see the tracker).  - **Rules sources:** which books the compendium uses for this campaign. New campaigns start with the SRD 5.2 and the server library. See [Compendium](/players/compendium/) and [Server library](/players/library/).

Players see the same rules read-only under **Campaign rules**, so nothing about how the table is run is hidden from them.
